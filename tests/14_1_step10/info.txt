Подготовка к заданию:
Продолжим работать с файлом people_names.txt.

Задание
Всё задание займёт у вас 3 строки кода:

Откройте файл people_names.txt, с помощью with и open() и присвойте объект файла в псевдоним names.
Среди аргументов в open() укажите только два: имя файла и кодировку utf-8. Указывать режим 'r' не нужно.
С помощью генератора списков, создайте список my_list состоящий из всех строк файла.
В генераторе используйте переменную line. Например: line for line in файл.
Сделайте так, чтобы строки, которые попадут из файла в список, не содержали \n.
То есть уберите \n уже на этом этапе кода.
Выведите на экран список my_list. Пример вывода:
['Вася', 'Маша', 'Настя', 'Вера', 'Гриша', 'Артём', 'Миша', 'Валера', 'Костя', 'Виталя', 'Толян']


Проверка
Запустите программу и посмотрите на результат.
Если всё сделано так, как в примере выше, то есть все строки без \n, то вы всё сделали правильно.
