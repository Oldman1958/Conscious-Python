Подготовка к заданию:
Продолжим работать с файлом people_names.txt.

Задание
Всё задание займёт у вас 3 строки кода:

Откройте файл people_names.txt, с помощью with и open() и присвойте объект файла в псевдоним names.
Среди аргументов в open() укажите только два: относительный путь к файлу и кодировку utf-8.
Указывать режим 'r' не нужно.
Создайте список из всех строк файла и присвойте его в переменную list_files. Каждый элемент списка является строкой.
Например первый элемент – это первая строка из файла. Для создания list_files используйте недавно изученный метод.
Выведите на экран четвёртую строку файла people_names.txt. Для вывода используйте print() и переменную list_files.
Проверка
Запустите программу и посмотрите на результат. Если всё сделано правильно, на экране появится строка Вера.

Скопируйте ваш код и вставьте для решения задания
В качестве ответа, вставьте 3 строки кода.

Комментарий
Параметр end использовать не нужно. И помните что индексация начинается с 0.
