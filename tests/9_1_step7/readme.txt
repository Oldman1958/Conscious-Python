Подготовка к заданию:
Продолжим работать с файлом people_names.txt.

Задание
Всё задание займёт у вас 5 строк кода:

Откройте файл people_names.txt, с помощью with и open() и присвойте объект файла в псевдоним names.
Среди аргументов в open() укажите только два: относительный путь к файлу и кодировку utf-8.
Указывать режим 'r' не нужно.
Выведите на экран первую строку файла (Вася) с помощью метода .readline().
Выведите на экран вторую строку файла (Маша) с помощью метода .readline().
Верните курсор в начало файла с помощью недавно изученного метода.
Выведите на экран снова первую строку файла (Вася) с помощью метода .readline().
Для более красивого вывода, в функции print() в этот раз используйте параметр end равный пустой строке '',
чтобы итоговый результат вывода выглядел вот так:

Вася
Маша
Вася


Проверка
Запустите программу и посмотрите на результат.
Если всё сделано так, как в примере выше, то есть без пустых строк, то вы всё сделали правильно.
