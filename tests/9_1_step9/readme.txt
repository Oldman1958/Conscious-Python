Подготовка к заданию:
Продолжим работать с файлом people_names.txt.

Задание
Всё задание займёт у вас 3 строки кода:

Откройте файл people_names.txt, с помощью with и open() и присвойте объект файла в псевдоним names.
Среди аргументов в open() укажите только два: имя файла и кодировку utf-8. Указывать режим 'r' не нужно.
С помощью цикла for пройдитесь по всему файлу. В цикле используйте переменную line по файлу. Например:
for line ...


Выведите на экран все строки файла.
Сделайте так, чтобы каждое имя выводилось на новой строке и чтобы не было пустых строк.
Использовать параметр end в функции print() нельзя.
Пример вывода:

Вася
Маша
Настя
Вера
Гриша
Артём
Миша
Валера
Костя
Виталя
Толян


Проверка
Запустите программу и посмотрите на результат.
Если всё сделано так, как в примере выше, то есть без пустых строк, то вы всё сделали правильно.
